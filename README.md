# Student Burnout Prediction System

## Overview
This project predicts student burnout risk using machine learning techniques and provides analytical insights through a Power BI dashboard.

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis
- Burnout Risk Prediction using Machine Learning
- Interactive Power BI Dashboard
